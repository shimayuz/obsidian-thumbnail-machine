# Thumbnail Machine - Obsidian プラグイン

YouTube、note、Udemy向けのサムネイルをAIで自動生成するObsidianプラグインです。

## 特徴

### 🎨 マルチプラットフォーム対応
- **YouTube**: 1280x720 (16:9) - 動画サムネイル
- **note**: 1280x670 (1.91:1) - 記事アイキャッチ
- **Udemy**: 1280x720 (16:9) - コースサムネイル

### 🖼️ 参照画像で合成生成
- **最大2枚**の参照画像をアップロード可能
- 対応形式: PNG, JPEG, WebP
- nano-banana Proが参照画像を使って合成写真風のサムネイルを生成

### 📝 ノートに自動挿入
- 生成完了後、画像リンクをノートのトップに自動挿入
- Frontmatterがある場合はその直後に配置
- 設定でON/OFF切り替え可能（OFFの場合はクリップボードにコピー）

### 🤖 AI自動抽出
ノートの内容から以下を自動抽出：
- タイトル（H1、frontmatter、ファイル名）
- サブタイトル（H2、description）
- キーワード（タグ、#ハッシュタグ）

### 🎨 6種類のデザインスタイル
- **モダン**: クリーンでプロフェッショナル
- **大胆**: インパクト重視
- **ミニマル**: シンプルで洗練
- **グラデーション**: 鮮やかな背景
- **写真ベース**: リアルな背景
- **イラスト風**: クリエイティブなグラフィック

## インストール

### 手動インストール

```bash
# リポジトリをクローン
git clone <repository-url>
cd obsidian-thumbnail-machine/plugin

# 依存関係をインストール
npm install

# ビルド
npm run build
```

ビルド後、以下のファイルを Obsidian の `<vault>/.obsidian/plugins/thumbnail-machine/` にコピー：
- `main.js`
- `manifest.json`
- `styles.css`

## 設定

### 必須: API キー

設定画面で以下を設定：

- **KIE API Key**
  - 高品質な画像生成
  - カスタムサイズ対応

### オプション設定

| 設定項目 | 説明 | デフォルト |
|---------|------|-----------|
| デフォルトプラットフォーム | 生成時の初期選択 | YouTube |
| デフォルトスタイル | デザインスタイル | モダン |
| 言語 | 生成テキストの言語 | 日本語 |
| デフォルトの場所 | 保管庫直下 or 指定フォルダ | 指定フォルダ |
| 指定フォルダ | サムネイルの保存先（入力時にフォルダ候補を表示） | attachments/thumbnails |
| ファイル名フォーマット | 保存ファイル名の形式 | {title}-{platform}-{timestamp} |
| ノートに自動挿入 | 生成後に画像リンクをノートのトップに挿入 | ON |

### カスタムプロンプト

AIへの追加指示を設定可能：
- **プレフィックス**: プロンプトの先頭に追加
- **サフィックス**: プロンプトの末尾に追加

例：
```
プレフィックス: 青色を基調としたデザインで、
サフィックス: テキストは白色で読みやすく配置してください。
```

## 使い方

### 基本的な使い方（訴求軸選択）

1. Markdownノートを開く
2. サイドバーの🖼️アイコンをクリック、または `Cmd/Ctrl + P` → `Thumbnail Machine: Generate Thumbnail`
3. モーダルでタイトル・プラットフォーム・スタイルを確認・編集
4. **「訴求軸を選択...」ボタン**をクリック
5. 25種類の訴求軸から**最大3つ**を選択して「決定」
6. （任意）**「画像を追加...」ボタン**で参照画像をアップロード（最大2枚）
7. 「生成する」をクリック
8. 選択した訴求軸ごとにサムネイルが生成される
9. 生成完了後、画像リンクがノートのトップに自動挿入される

> **💡 ヒント**: Frontmatterがなくても、モーダルでタイトルを入力すれば生成できます。

### クイック生成

特定プラットフォーム向けにワンクリックで生成（訴求軸なし）：

- `Generate YouTube Thumbnail` - YouTube用
- `Generate note Thumbnail` - note用
- `Generate Udemy Thumbnail` - Udemy用

## トラブルシューティング

### 「KIE API key not configured」エラー
→ 設定画面でKIE APIキーを設定してください

### 画像が生成されない
→ APIキーが有効か確認してください
→ ネットワーク接続を確認してください

### 「訴求軸を少なくとも1つ選択してください」エラー
→ 「訴求軸を選択...」ボタンから最低1つの訴求軸を選択してください

### 参照画像のアップロードに失敗する
→ 画像サイズが10MB以下か確認してください
→ 対応形式（PNG, JPEG, WebP）か確認してください

### 画像がノートに挿入されない
→ 設定画面で「ノートに自動挿入」がONになっているか確認してください

## プロンプトのカスタマイズ

生成されるプロンプトを調整したい場合は、以下のファイルを編集してください。

### 訴求軸のプロンプト要素

**ファイル**: `plugin/src/types.ts`

各訴求軸の `promptElements` を編集することで、生成されるプロンプトを調整できます。

```typescript
export const APPEAL_AXIS_CONFIGS: AppealAxisConfig[] = [
  {
    id: 'authority',
    name: '権威性',
    description: '専門家や実績をアピール',
    promptElements: 'authoritative design with expert credentials, professional badges, certification symbols',
  },
  // ...
];
```

### プロンプト生成ロジック

**ファイル**: `plugin/src/api/api-client.ts`

- `buildPrompt()`: 通常のプロンプト生成
- `buildAppealAxisPrompt()`: 訴求軸ベースのプロンプト生成

```typescript
// 訴求軸プロンプトのフォーマット例
let prompt = `YouTube thumbnail, professional design, `;
prompt += `${axisConfig.promptElements}, `;
prompt += `Japanese text "${request.title}", `;
```

### 編集後の反映

```bash
cd plugin
npm run build
```

ビルド後、Obsidianでプラグインを再読み込みしてください。
